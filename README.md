# Здоровье — личная база данных

Веб-приложение для одного человека: дневник самочувствия, визиты к врачам с документами, лекарства с чек-листом приёма, КОК и цикл, анализы с графиками, расходы для налогового вычета. Работает на iPhone и ноутбуке с одной базой данных.

## Стек

- Node.js ≥ 22.13 (используется встроенный `node:sqlite`, никаких нативных сборок)
- Express + multer (загрузка файлов)
- Фронтенд — один HTML + CSS + JS без фреймворков и сборки
- Данные: `data/health.db` (SQLite) и `data/uploads/` (прикреплённые файлы)

## Запуск на ноутбуке

```bash
npm install
copy .env.example .env      # и впиши HEALTH_PASSWORD, если хочешь пароль
npm start
```

Открой http://localhost:3000.

С телефона в той же Wi-Fi сети: узнай IP ноутбука (`ipconfig` → IPv4) и открой `http://192.168.x.x:3000`. Возможно, придётся разрешить порт 3000 в брандмауэре Windows.

## Локальный режим: автозапуск и резервные копии

`tools\install-autostart.ps1` (уже выполнен) создаёт задачу планировщика **Health Server** без прав администратора: при входе в Windows сервер запускается без окна (лог в `data\server.log`) и перезапускается при падении. Вручную: `Start-ScheduledTask -TaskName "Health Server"` / `Stop-ScheduledTask …`. Удалить: `Unregister-ScheduledTask -TaskName 'Health Server' -Confirm:$false`.

Данные живут в `data\health.db` (SQLite) и `data\uploads\`. Ничего не сбрасывается само: база теряется только если удалить папку `data`.

**Резервные копии — раз в месяц, вручную.** Когда с последней копии прошло 30 дней, на главной появляется жёлтая карточка «Пора сделать резервную копию» с кнопкой скачивания JSON. Папку `data\uploads` (файлы анализов) копируй отдельно. Альтернатива одной командой — zip базы и файлов: `powershell -ExecutionPolicy Bypass -File tools\backup.ps1` (кладёт в `OneDrive\HealthBackups`). Восстановление: раздел «Экспорт» → «Восстановить из файла» (JSON) либо распаковать zip в `data\` при остановленном сервере.

С телефона в домашней Wi‑Fi: `http://<IPv4 ноутбука>:3010` (узнать: `ipconfig`, строка «Беспроводная сеть» → IPv4). Ноутбук должен быть включён и не спать; VPN/сотовая сеть на телефоне — выключены.

## Размещение на хостинге (чтобы работало откуда угодно)

Нужен хостинг с Node.js (VPS, Railway, Render, Fly.io, Timeweb Cloud и т.п.). Статический хостинг (GitHub Pages) не подойдёт — данным нужен сервер.

1. Загрузи проект (без `node_modules` и `data`).
2. Переменные окружения:
   - `HEALTH_PASSWORD` — **обязательно**, иначе база открыта всем.
   - `SECURE_COOKIE=1` — если сайт по https (на хостингах почти всегда).
   - `DATA_DIR` — папка для базы и файлов на постоянном диске (volume), иначе данные пропадут при пересборке.
   - `PORT` — если хостинг задаёт свой.
3. `npm install && npm start`.

Есть `Dockerfile`: `docker build -t health . && docker run -p 3000:3000 -v health-data:/data -e HEALTH_PASSWORD=секрет -e SECURE_COOKIE=1 health`.

## Установка на iPhone как приложение

Открой адрес в Safari → «Поделиться» → «На экран Домой». Иконка появится рядом с обычными приложениями, откроется без адресной строки.

## Цикл из Flo / Apple Health

Прямого API у Flo и Apple Health нет. Два пути (оба в разделе «Экспорт»):

1. **Файл.** Flo → Настройки → включить Apple Health. Затем Здоровье → профиль → «Экспортировать медданные» → распаковать ZIP в «Файлах» → загрузить `export.xml`. Дни менструации становятся циклами, межменструальные кровотечения — записями «Мазня» в дневнике. Повторный импорт не дублирует.
2. **Автоматически через «Команды» (Shortcuts).** Ежедневная автоматизация читает образцы «Менструация» из Здоровья и отправляет даты `POST /api/cycles/sync` с заголовком `X-Api-Token` (токен показан в разделе «Экспорт»). Тело — JSON `{"dates":[...]}` или просто текст с датами (`yyyy-MM-dd`, `dd.mm.yyyy`, «9 сент. 2026 г.»). Сайт должен быть доступен с телефона.

## Гормональная терапия

У курса есть галочка «Гормональная терапия»: размер пачки и режим — перерыв 7/4 дня (КОК) или непрерывно (гестагены, например диеногест при эндометриозе). На главной — номер таблетки в пачке, пропуски, дата перерыва/новой пачки.

## Резервные копии

Раздел «Экспорт» → «Скачать копию» — весь JSON. Прикреплённые файлы копируй из `data/uploads/`. Восстановление — там же, из файла (заменяет все данные).

## Структура

```
server.js        — API, авторизация, загрузка файлов
db.js            — схема SQLite и CRUD-хелперы
public/          — фронтенд (index.html, app.js, style.css, login.html)
tools/           — генератор PNG-иконок
data/            — база и файлы (создаётся автоматически, в .gitignore)
```

## API (кратко)

Универсальный CRUD `/api/<таблица>` (`GET`, `GET /:id`, `POST`, `PUT /:id`, `DELETE /:id`) для таблиц: `diary, visits, courses, intakes, labs, lab_results, cycles, expenses, reminders, doctors, places, medications, episodes, files`. Фильтры — по любой колонке (`?episode_id=3`), по датам `?from=&to=`, `?limit=`.

Специальные: `POST /api/import/apple-health` (multipart `file` = export.xml), `POST /api/cycles/sync` (даты текстом/JSON, авторизация заголовком `X-Api-Token`), `GET|POST /api/settings/token`, `GET /api/today?date=`, `POST /api/intakes/toggle`, `POST /api/courses/:id/new-pack`, `GET /api/labs/indicators`, `GET /api/expenses/summary?year=`, `GET /api/export`, `POST /api/import`, `POST /api/upload` (multipart), `GET /files/:id`.

При сохранении визита/анализа/курса с ценой автоматически создаётся расход; при `next_date` у визита и `end_date` у курса — напоминание.
