# Здоровье — личная база данных

Приложение для одного человека: дневник самочувствия, визиты к врачам с документами, лекарства с чек-листом приёма, гормональная терапия и цикл, анализы с графиками, расходы для налогового вычета, отчёт для врача.

**Основной режим — автономный:** приложение открывается по ссылке (GitHub Pages), ставится на экран «Домой» iPhone и дальше работает без интернета. Все данные и файлы хранятся в самом устройстве, никуда не отправляются. Сервер не нужен.

## Публикация на GitHub Pages

1. Создай на github.com **публичный** репозиторий (в коде нет личных данных; Pages для приватных репозиториев требует платный план).
2. Запушь проект: `git remote add origin https://github.com/ЛОГИН/health.git && git push -u origin main`.
3. В репозитории: Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/docs` → Save.
4. Через минуту приложение доступно по адресу `https://ЛОГИН.github.io/health/`.

Обновления: после `git push` новая версия подхватится при следующем открытии приложения (если сеть есть).

## Установка на iPhone

Открой ссылку в Safari → «Поделиться» → «На экран Домой». Дальше открывай только с иконки.

**Важно:** данные лежат в хранилище браузера этого устройства. Если удалить иконку с экрана «Домой» или очистить данные Safari — база удалится вместе с ними. Раз в месяц приложение само напомнит сохранить копию (карточка на главной).

## Резервные копии и перенос между устройствами

Раздел «Экспорт» (на телефоне: Ещё → Экспорт):

- **Сохранить копию** — полный JSON с прикреплёнными PDF/фото. На телефоне откроется меню «Поделиться» — отправь в «Файлы», iCloud или себе в мессенджер.
- **Только данные** — лёгкий файл без вложений.
- **Восстановить из файла** — заменяет все данные на устройстве данными из копии.

На ноутбуке открывается та же ссылка, но база там своя. Перенос: телефон → «Сохранить копию» → файл на ноутбук → «Восстановить из файла». Автосинхронизации в автономном режиме нет.

## Цикл из Flo / Apple Health

Прямого API у Flo и Apple Health нет, но данные переносятся файлом. Flo → Настройки → включить Apple Health. Затем Здоровье → фото профиля → «Экспортировать медданные» → сохранить ZIP в «Файлы» → нажать на него (распакуется) → в приложении «Экспорт» → «Загрузить export.xml». Дни менструации становятся циклами, межменструальные кровотечения — записями «Мазня» в дневнике. Повторный импорт не дублирует. Файл читается потоком — большой размер не страшен.

## Гормональная терапия

У курса есть галочка «Гормональная терапия»: размер пачки и режим — перерыв 7/4 дня (КОК) или непрерывно (гестагены, например диеногест при эндометриозе). На главной — номер таблетки в пачке, пропуски, дата перерыва/новой пачки.

## Структура

```
docs/               — приложение (статические файлы для GitHub Pages)
  index.html, app.js, style.css
  localapi.js       — автономное хранилище: IndexedDB + те же «эндпоинты», что у сервера
  sw.js             — service worker (работа офлайн)
  login.html        — только для серверного режима
server.js, db.js    — необязательный серверный режим (см. ниже)
tools/              — генератор иконок, скрипты для серверного режима на Windows
```

## Необязательный серверный режим

Тот же интерфейс, но данные в SQLite на сервере — общая база для всех устройств. Нужен Node.js ≥ 22.13 и постоянно работающий сервер (VPS или включённый ноутбук).

```bash
npm install
copy .env.example .env      # HEALTH_PASSWORD, PORT
npm start                   # http://localhost:3010
```

Данные — `data/health.db` и `data/uploads/`. Для хостинга: `Dockerfile`, `docker-compose.yml` + `Caddyfile` (автоматический HTTPS), переменные `HEALTH_PASSWORD`, `SECURE_COOKIE=1`, `DATA_DIR`. Дополнительно в этом режиме работает `POST /api/cycles/sync` с заголовком `X-Api-Token` для автоматизации через iOS «Команды». Автозапуск на Windows: `tools\install-autostart.ps1`; zip-бэкап: `tools\backup.ps1`.

API: универсальный CRUD `/api/<таблица>` (`GET`, `GET /:id`, `POST`, `PUT /:id`, `DELETE /:id`) для `diary, visits, courses, intakes, labs, lab_results, cycles, expenses, reminders, doctors, places, medications, episodes, files`; фильтры по колонкам, `?from=&to=`, `?limit=`. Специальные: `/api/today?date=`, `/api/intakes/toggle`, `/api/courses/:id/new-pack`, `/api/labs/indicators`, `/api/expenses/summary?year=`, `/api/export`, `/api/import`, `/api/upload`, `/api/import/apple-health`, `/files/:id`. При сохранении визита/анализа/курса с ценой автоматически создаётся расход; при `next_date` у визита и `end_date` у курса — напоминание. Автономный слой (`localapi.js`) повторяет эту же логику.
